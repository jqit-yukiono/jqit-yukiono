### Yuki Ono @ JQIT 👋

株式会社JQIT のエンジニアです。Jenkins・Kubernetes・n8n・生成AI を組み合わせて、開発と運用の「めんどう」を自動化しています。
<br><sub>Engineer at JQIT. I automate the boring parts of dev & ops with Jenkins, Kubernetes, n8n and LLMs.</sub>

## 🚀 Focus / 取り組んでいること

- 🤖 **AI × CI/CD** — GitHub Copilot CLI で PR を自動レビュー、Claude Code Action で Actions の失敗を自己修復
  <br><sub>LLM-powered PR reviews and self-healing GitHub Actions pipelines.</sub>
- 🔧 **Jenkins on Kubernetes** — エージェントコンテナで Spring Boot をビルド・デプロイ、Mac 1 台で iOS を TestFlight へ配信
  <br><sub>Kubernetes-native Jenkins agents for Spring Boot and iOS release pipelines.</sub>
- 📨 **Ops automation** — Jenkins の失敗ログを n8n で回収し、Claude が原因を調べて Slack に通知
  <br><sub>Failed builds are triaged by Claude via n8n and reported to Slack.</sub>
- 🌐 **n8n 日本語化** — n8n の UI 翻訳に取り組み中
  <br><sub>Working on Japanese localization for n8n.</sub>
